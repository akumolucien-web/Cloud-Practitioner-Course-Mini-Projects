# Cloud Practitioner Course Mini Projects

Hands-on mini projects built by our study group while taking the **AWS Certified Cloud Practitioner** course on **AWS Skill Builder**.

## How We Work
1. **Use your own branch:** Create a branch for your work (e.g., `lucien/s3-static-site`)—do not push directly to `main`.
2. **Add a short README:** Inside your project folder, briefly note what you built, how it works, and any lessons learned.
3. **Open a Pull Request:** When a mini project is ready for feedback or review, open a PR into `main`.

## AWS Safety Rules
- **Never commit AWS credentials** (access keys, secret keys, or `.env` files).
- **Set a billing alert** in AWS Budgets before launching resources.
- **Clean up after labs:** Delete EC2 instances, databases, NAT gateways, and test S3 buckets when you finish testing.
